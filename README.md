# PulseIQ

Modern AI-powered SaaS analytics dashboard built with Vue 3.

## Features

- AI analytics dashboard
- Realtime notification system
- Interactive charts
- Workspace management
- CRM pipeline
- Billing & subscriptions
- Responsive enterprise UI
- Dark / light mode
- Command palette
- Animated transitions
- Glassmorphism design system

## Stack

- Vue 3
- Vite
- Pinia
- TailwindCSS
- Chart.js
- VueUse Motion
- Vue Toastification

## Installation

```bash
npm install
npm run dev
